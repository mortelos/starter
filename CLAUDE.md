# Claude Code Instructions

Read `AGENTS.md` first.

The public MortelOS documentation is the source of truth:

https://mortelos.nl/docs

For clean machine or tooling preparation, use the local `mortelos-tooling-setup` skill first. Trigger it for missing Herd, PHP, Composer, Node, GitHub access, MortelOS CLI, DBngin, TablePlus, or `mortelos new` setup. For new portal work, use the local `setup-portal` skill when available. These skills point to the public docs and should not duplicate them locally.
